在额度重置前，先看清信号。

Codex Reset Radar 无需登录即可监控可能的官方重置信号；登录 ChatGPT 后可额外显示个人额度与重置券建议。

  1. 1
    安装后即可使用

    公开信号雷达、时间预测和信号通知都不需要登录 ChatGPT。

  2. 2
    可选：登录 ChatGPT

    仅在需要个人额度、重置券状态和个性化建议时登录，不要求 API Key。

  3. 3
    按需调整设置

    可以配置系统通知、可信度阈值和显示时区。

不上传令牌、账户标识或使用记录。不会自动兑换重置券。
