在额度重置前，先看清信号。

Codex Reset Radar 监控可能的官方重置信号，并结合你的额度和重置券过期时间给出只读建议。

  1. 1
    保持 ChatGPT 登录

    插件复用当前浏览器会话读取 Codex 额度，不要求 API Key。

  2. 2
    允许系统通知

    高可信信号、重置券即将过期或额度受限时才提醒。

  3. 3
    确认你的时区

    所有 UTC 时间戳都会按系统时区换算，也可以手动指定 IANA 时区。

不上传令牌、账户标识或使用记录。不会自动兑换重置券。
