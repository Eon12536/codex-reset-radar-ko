리셋 소식과 내 잔여량을 한눈에.

Codex 리셋 레이더 보안 강화판입니다. 공개 소식을 확인하고, 계정 조회를 직접 켜면 내 잔여량과 리셋권도 볼 수 있습니다.

  1. 1
    설치 후 공개 소식 확인

    공개 리셋 소식, 예상 시간대, 관련 알림은 ChatGPT 로그인 없이 사용할 수 있습니다.

  2. 2
    내 잔여량을 보려면 ChatGPT 로그인

    아래 연결 버튼으로 계정 조회를 켠 뒤 같은 크롬 프로필에서 ChatGPT에 로그인하세요. API 키는 필요하지 않습니다.

  3. 3
    알림과 시간대 설정

    확인 간격, 알림을 받을 신뢰도, 방해 금지 시간, 표시 시간대를 설정하세요.

로그인 후 확장을 다시 열면 잔여량 연결을 확인합니다.

계정 조회는 기본 꺼짐입니다. 토큰은 저장하지 않으며 리셋권을 자동 사용하지 않습니다.
