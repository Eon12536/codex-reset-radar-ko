# Codex 리셋 레이더 사용법

[프로젝트 소개·실제 화면](../README.md) · [최신 설치 파일](https://github.com/Eon12536/codex-reset-radar-ko/releases/latest)

## 1. 설치하기

이 안내는 데스크톱 Chrome·Edge 기준입니다. 현재 배포는 확장 스토어 설치가 아닌 ZIP 설치 방식입니다.

1. 최신 릴리스의 **Assets**에서 `CodexReset-Radar-KO-버전.zip`을 다운로드합니다. `Source code (zip)`은 개발용 소스이므로 설치용 ZIP을 선택하세요.
2. 다운로드한 파일의 압축을 계속 보관할 폴더에 풉니다.
3. Chrome은 `chrome://extensions/`, Edge는 `edge://extensions/`를 엽니다.
4. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. `manifest.json`과 `src`, `assets` 폴더가 들어 있는 위치를 지정합니다. 폴더가 한 겹 더 들어 있다면 안쪽 폴더를 선택하세요.
6. 브라우저의 확장 메뉴에서 Codex 리셋 레이더를 고정합니다.

설치 폴더는 삭제하거나 이동하지 마세요. 공개 ZIP에는 개발자의 로그인 정보나 개인 설정이 포함되지 않습니다. 각자 본인의 브라우저에서 연결합니다.

## 2. 처음 설정하기

### 공개 리셋 소식만 보고 싶을 때

- 확장 **설정 → 감시 설정**에서 **공개 리셋 소식**과 **OpenAI · Tibo · VB의 Codex 소식**을 확인합니다.
- **X 글·답글 직접 확인**에 필요한 접근 권한을 허용합니다. 공개 소식 감시가 켜져 있으면 직접 확인도 포함됩니다.
- 같은 브라우저에서 X에 로그인해야 할 수 있습니다.
- 팝업의 **지금 확인**을 누릅니다. 수집 중에는 비활성 X 확인 탭이 열릴 수 있으며 정상 종료 후 정리됩니다. 일부 수집 실패나 답글 대기가 표시되면 완전 수집으로 보지 마세요.
- 기본 확인 주기는 15분입니다. 컴퓨터와 Chrome이 꺼져 있는 동안에는 이 확장이 실행되지 않습니다. 다시 켜거나 절전에서 복귀하면 확인을 시도합니다.

### 내 잔여량·리셋권도 보고 싶을 때

**설정 → 감시 설정 → 내 잔여량·리셋권(선택)**을 켜고 같은 브라우저의 ChatGPT에 로그인한 뒤 **연결 확인**을 실행합니다. Codex의 5시간·주간 잔여량, 조회 가능한 초기화 시각과 리셋권 보유·만료 상태를 확인할 수 있습니다.

공개 글에서 ‘리셋 완료’나 ‘리셋권 지급’을 탐지한 것과 내 계정의 실제 반영 여부는 다릅니다. 실제 계정 상태는 잔여량·리셋권 조회 결과를 확인하세요.

### Chat 모델별 집계가 필요할 때

**Chat · 계정 연결 및 모델별 카운터**를 켭니다. 다른 기기에 동기화된 기록도 확인하려면 **계정 기록 동기화 · 다른 기기 포함**을 별도로 켭니다.

- 요금제 확인은 최대 45초 걸릴 수 있어, 처음에는 이전 값이 잠시 보일 수 있습니다.
- 재확인에 실패하면 표시된 이유를 확인하세요. 실제 구독이 변경되는 기능은 아닙니다.
- 모델별 횟수와 잔여량은 확인한 기록에 기반한 추정입니다. 공식 ChatGPT 사용 한도를 실시간으로 모두 읽는 기능은 아닙니다.
- **Codex 기준 로컬 집계**는 Codex 회복 시각을 기준으로 이 확장의 집계를 조정하는 선택 기능입니다. ChatGPT 서버의 한도를 초기화하지 않습니다.

## 3. 팝업 읽는 법

| 위치 | 의미·사용법 |
| --- | --- |
| 남은 사용량 | 5시간·주간 Codex 잔여량과 초기화 시각 |
| 느낌표·경고 문구 | 만료 임박 등 주의 상태. 남은 사용량 옆 안내와 리셋권 상태 확인 |
| 탐지 시도·수집 상태 | 마지막 시도 시점과 일부 실패·대기 여부. 시도 시각만으로 전체 성공을 뜻하지 않음 |
| 지금 확인 | 새 소식과 연결된 계정 상태 수동 확인. 저장된 과거 소식은 유지 |
| 날짜별 소식 카드 | 하루 요약, 분류별 건수, 확인 가능한 리셋 일정 |
| 분류 배지 | 리셋 예고 / 리셋 완료 / 리셋 추정 / 리셋권 / 신모델 출시. 해당 건수가 있을 때 강조 |
| 원문 링크 | 작성자의 실제 글을 열어 문맥 직접 확인 |
| 기간설정 | 기본 이번 달·지난달 표시에서 특정 연도·월로 전환. 저장·복구된 기록만 표시 |
| 리셋권 상태 | 현재 조회한 리셋권 보유 수·만료 시각 확인 |

**리셋 시각**은 명시된 시간대를 우선하고, 확인 가능한 상대 날짜 표현을 해석해 표시합니다. 추정·후속 글 기준 표시는 직접적인 시간 확정과 구분해서 읽어 주세요. 정확한 시각이 없으면 원문의 시간 표현이나 미확인 상태를 표시할 수 있습니다.

팝업에서 국가를 선택하고 필요한 경우 설정의 시간대 항목도 확인하세요. 현재 새 모델 출시 감지는 모델 소식을 알리는 기능이며, 새로운 모델의 공식 한도표를 자동으로 갱신하지는 않습니다.

## 4. Windows 알림

**설정 → 알림 → Windows 알림 테스트 → 테스트 알림**을 눌러 배너 또는 알림 센터에 표시되는지 확인합니다.

- 공개 소식은 기본적으로 선택 국가의 하루에 한 번 요약 알림을 보냅니다. **같은 날 추가 글은 팝업에만 반영될 수 있습니다.**
- 잔여량 회복·리셋권 지급·만료 알림은 공개 소식의 하루 요약과 별도입니다.
- 만료 알림은 만료 시각을 확인할 수 있는 리셋권에 대해 기본 3일·2일·1일 전 단계로 안내합니다. 이미 사용했거나 만료된 리셋권은 상태 재확인 결과에 따라 제외합니다.
- 복귀 알림은 다시 수집한 뒤 안내하며, 네트워크 상태 등에 따라 지연될 수 있습니다. 꺼져 있던 기간의 모든 글을 보장하는 것은 아닙니다.
- Windows의 알림 허용·방해 금지, Chrome/Edge의 알림 허용 상태도 확인하세요. 확장의 방해 금지 시간 설정과 OS 설정은 별개입니다.
- 진단의 **Chrome 접수**는 브라우저가 요청을 받아들였다는 뜻입니다. 실제 OS 배너나 소리까지 확인했다는 뜻은 아닙니다.

## 5. 보조 확인과 기기 AI

**Telegram 보조 확인:** 공개 채널의 X 글 번호만 보조 후보로 참고합니다. 기본 X 수집을 대체하지 않으며, 원문의 작성자·본문을 확인한 뒤 반영합니다. Telegram 계정으로 메시지를 전송하는 기능이 아닙니다.

**예전 리셋 글 복구:** 공개 기록 사이트의 Tibo 원문 링크를 후보로 가져와 재확인합니다. 접속·로그인·조회 시간에 따라 일부 글은 복구되지 않을 수 있습니다. 복구한 오래된 글은 새 알림으로 다시 보내지 않습니다.

**기기 AI:** 지원되는 Chrome 내장 모델이 공개 글의 의미 판정을 보조합니다. 설정에서 모델 준비 상태를 확인할 수 있습니다. 유료 Claude API나 Codex 추론 토큰을 사용하지 않지만, 기기 자원을 사용하고 모델 준비가 필요합니다. AI 판정도 틀릴 수 있습니다.

## 6. 자주 묻는 문제

| 증상 | 확인할 내용 |
| --- | --- |
| 최신 글이 보이지 않음 | X 로그인·접근 권한 확인 → 지금 확인 → 설정의 글·답글 수집 상태 확인. 일부 실패는 성공으로 간주하지 않음 |
| 새 카드가 생겼는데 알림이 없음 | 오늘의 하루 요약이 이미 처리됐는지, 과거 복구 글인지, 알림 설정에서 제외됐는지 확인 |
| 테스트 알림도 안 보임 | 브라우저/Windows 알림 허용·방해 금지 및 알림 센터 확인 |
| Pro인데 Plus가 잠깐 표시됨 | 팝업을 연 뒤 요금제 확인이 끝날 때까지 최대 45초 대기. 계속되면 실패 사유와 버전 확인 |
| 확인 탭이 남음 | 수집이 진행 중인지 확인. 고정·이동·사용자가 선택한 ChatGPT 탭 등은 보호될 수 있음. 중단 상태라면 설정 안내에 따라 확인 탭만 정리 |
| 지난달 소식이 없음 | 기간설정과 저장된 기록 확인. 설치 전에 놓친 모든 글을 자동 보유하는 것은 아님 |
| 다른 PC에서 기록이 안 보임 | 리셋 탐지 기록은 해당 브라우저의 로컬 데이터. Chat 계정 기록 동기화와는 다른 기능 |
| 새로고침했는데 버전이 같음 | 최신 ZIP을 실제로 로드한 설치 폴더에 덮어썼는지 확인 |

## 7. 업데이트·공유·피드백

최신 설치 ZIP을 기존 폴더에 덮어쓰고 확장 관리에서 **새로고침**합니다. 같은 확장을 삭제하지 않아야 로컬 설정·기록을 유지할 수 있습니다. ZIP 설치는 자동 업데이트되지 않습니다.

다른 사람에게는 [프로젝트 링크](https://github.com/Eon12536/codex-reset-radar-ko) 또는 [최신 릴리스 링크](https://github.com/Eon12536/codex-reset-radar-ko/releases/latest)를 공유하면 됩니다.

문제는 [오류 신고](https://github.com/Eon12536/codex-reset-radar-ko/issues/new?template=bug_report.yml)에 **버전·브라우저·재현 순서·수집/알림 진단 문구·공개 원문 링크**를 적어 주세요. 인증 토큰·쿠키·계정 ID·대화 본문·원본 API 응답은 올리지 마세요. [개인정보 처리 안내](../PRIVACY.md)
